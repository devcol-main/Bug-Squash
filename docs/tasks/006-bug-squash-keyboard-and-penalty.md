# Task 006: Bug Squash 키보드 조작 + 빈 칸 탭 페널티

상태: 확정 (구현 시작 가능)
작성일: 2026-10-14
플랫폼: 웹 (TypeScript + Canvas 2D). 저장소 `devcol-arcade-web`, 규칙은 `CLAUDE.md`
선행: Task 004, 005가 main에 머지됨. main에서 브랜치 `task/006-bug-squash-keyboard` 생성
범위: `games/bug-squash`만. `games/stack-up/`은 수정하지 않는다. `shared/`는 수정하지 않는다.

## 배경
- 지금은 마우스/터치로만 칸을 칠 수 있다. 키보드로도 칠 수 있게 한다
- 난이도를 높이기 위해, 오브젝트가 없는 칸을 잘못 치면 라이프가 깎이게 한다

## 1. 키보드 조작
- 키보드 왼쪽 4×4 구역을 보드에 그대로 대응한다
  ```
  4×4                3×3
  1 2 3 4            1 2 3
  Q W E R            Q W E
  A S D F            A S D
  Z X C V
  ```
- 3×3일 때는 `1 2 3 / Q W E / A S D`만 쓰고 `4, R, F, Z, X, C, V`는 칸이 없으므로 무시한다 (페널티 없음)
- 4×4로 확장되면 16개 키를 모두 쓴다. 확장 연출 중(1.5초)에는 core 규칙대로 탭을 무시한다
- 키는 **물리 위치(`KeyboardEvent.code`)** 로 판정한다. 한글 입력기, Dvorak 등 배열이 달라도 같은 위치의 키가 같은 칸이다
- 키를 누를 때(keydown) 한 번이 탭 한 번이다. 길게 눌러 반복되는 입력(`event.repeat`)은 무시한다
- Ctrl/Alt/Meta 조합 키는 무시한다 (브라우저 단축키와 충돌 방지)
- 키 하나를 누르고 있는 동안 다른 키를 누르면 그것도 독립된 탭이다 (동시 입력 가능)
- 키보드 입력은 마우스/터치와 **같은 입력 큐**로 들어가 같은 방식으로 core `tap(cell)`을 부른다
- 키보드 입력이 비활성인 경우: 타이틀, 게임 오버, 옵션 패널이 열려 있을 때, 닉네임 입력칸이나 버튼에 포커스가 있을 때 (기존 Space 시작/재시작, M 음소거 동작은 그대로 유지)
- 입력 좌표 → 칸 변환처럼 **키 → 칸 인덱스 변환은 순수 함수**로 분리해서 테스트한다 (그리드 크기별 키 목록, 범위 밖 키는 -1)
- **키 힌트:** 처음 키보드를 한 번 누른 뒤부터 각 칸의 왼쪽 위 타이틀바 자리에 해당 키 글자(`1`, `Q` …)를 작게 보여준다. 오브젝트 위에는 글자를 올리지 않는다. 마우스/터치만 쓰는 사람에게는 보이지 않는다. 옵션에서 따로 끄는 항목은 만들지 않는다
- 키 힌트는 Reduced motion과 무관하다 (정적 표시)

## 2. 빈 칸 탭 페널티
Task 004 핵심 규칙 8을 바꾼다.

| | 기존 | 변경 |
|---|---|---|
| 빈 칸(오브젝트가 없는 칸)을 탭 | 콤보만 리셋 | **라이프 -1**, 콤보 리셋 (점수 변화 없음) |
| 보드 밖, 칸 사이, 다른 화면을 탭 | 아무 일 없음 | 그대로 아무 일 없음 (콤보도 유지) |

- 마우스, 터치, 키보드 모두 같은 규칙이다
- 라이프가 0이 되면 즉시 게임 오버 (기존 규칙 그대로)
- 확장 연출 중, 게임 오버 이후의 탭은 무시한다 (기존 규칙 그대로)
- **유예 시간 없음 (사용자 결정):** 오브젝트가 방금 사라진 칸(잡았거나 시간이 끝남)도 즉시 빈 칸이다. 이미 잡은 버그를 연타하면 라이프가 깎인다. 유예 시간 설정값은 만들지 않는다
- core 이벤트: `emptyTap`에 `lifeDelta: -1`을 담고 `comboReset`, `lifeChanged`(, `gameOver`)가 뒤따른다. 이미 콤보가 0이면 `comboReset`은 기존 규칙대로 발행하지 않는다

### 연출 (빈 칸 탭 페널티)
- VFX: 칸이 빨갛게 깜박인다 (놓침과 같은 빨간 깜박임, 3번 연출 재사용), 라이프 블록이 깨진다 (기존)
- 오디오: 놓침 소리 (기존 SFX 재사용). 새 소리는 만들지 않는다
- 진동: 놓침과 같은 진동 (옵션의 Vibration 설정을 따름)
- 점수 팝업은 없다

## 3. 난이도와 문서
- 이 변경으로 난이도가 올라간다. 수치(`config.ts`) 조정은 이 Task 범위가 아니다. 플레이해 보고 사람이 결정한다
- 타이틀 화면의 안내 문구를 규칙에 맞게 영어로 갱신한다 (예: `Squash the bugs. Wrong cell costs a life.`). 키보드 안내(`1-4 Q-R A-F Z-V`)는 타이틀 하단에 작게 한 줄 넣는다
- `docs/tasks/004-bug-squash.md`의 규칙 8은 Task 006에서 바뀌었다는 한 줄 메모를 덧붙인다

## 하위 작업 순서
1. core: 빈 칸 탭 페널티 + 이벤트 + 테스트
2. 입력: 키 → 칸 순수 함수, 키보드 수집기(기존 큐 사용), main.ts 연결(비활성 조건, 기존 Space/M 유지) + 테스트
3. 연출 연결: 빈 칸 탭 이벤트 → VFX/오디오/진동 매핑, 키 힌트 표시, 타이틀 문구
4. 마무리: 문서 메모, 빌드 용량, 명세 체크리스트
