# Task 004: Bug Squash (웹 버전)

상태: 확정 (구현 시작 가능)
작성일: 2026-10-14
플랫폼: **웹 (TypeScript + Canvas 2D)**. Unity 아님. 저장소 `devcol-arcade-web`, 규칙은 `CLAUDE.md`
선행: Task 003이 main에 머지된 뒤, main에서 브랜치 `task/004-bug-squash` 생성. **에셋은 무료 + 상업적 사용 가능한 것만** (`docs/assets.md`에 기록), 가능하면 외부 에셋 없이 코드 합성

## 한 줄 요약
보드의 칸에서 튀어나오는 버그를 탭해서 잡는 두더지잡기류 게임. 섞여 나오는 "기능"을 탭하거나 버그를 놓치면 라이프가 깎이고, 라이프 3개를 다 잃으면 게임 오버. 45초에 보드가 3×3에서 4×4로 넓어진다.

## 출발점
- 시안 없음. Stack Up(`games/stack-up/`, Task 001~003 결과)의 구조, Neon 렌더링 방식(글로우 스프라이트 캐시), 합성 BGM/SFX, 옵션 패널, 최고 기록, DevCol 로고 배치, 리더보드 Mock을 그대로 따른다
- **Stack Up(`games/stack-up/`)은 건드리지 않는다.** 필요한 코드와 에셋(rng, 글로우 스프라이트, 별 패럴랙스, 오디오 구조, 기록/옵션, 폰트, 로고)은 `games/bug-squash/` 안에 복사해서 게임별로 따로 둔다
- `shared/`는 기존 `shared/leaderboard`만 쓴다 (나중에 대시보드 랭킹에서 게임별 기록을 확인하는 용도). 그 밖의 공통 모듈 추출은 하지 않는다

## 테마
- 칸 = 코드가 돌아가는 슬롯, 버그 = 잡아야 할 버그, 기능 = 건드리면 안 되는 정상 기능 (콘셉트만, **오브젝트 안 글자 없음**)
- 게임 오버 화면에 작은 글씨로 "Build failed"
- 게임 안의 모든 텍스트는 영어
- **IP 주의:** 기존 두더지잡기 게임/캐릭터의 외형을 쓰지 않는다. 버그와 기능은 단순한 기하 도형으로 그린다

## 디테일
- **움직이는 배경:** Stack Up과 같은 별/입자 패럴랙스 2~3겹, 그리드 은은한 깜박임 (Stack Up 코드를 bug-squash에 복사해서 사용)
- **VFX:**
  - 버그 잡기: 짧은 찌그러짐(squash) 후 사라짐 + 버그 색 입자 튐 + 칸 외곽선 플래시
  - 단단한 버그 1타: 금 간 표시 + 작은 흔들림
  - 골든 버그 잡기: 링 파동 + 금색 입자 + `+1 LIFE` 또는 `+50` 텍스트 팝업
  - 점수 팝업: 잡은 칸 위에 `+20` 같은 숫자가 떠오르며 페이드
  - 기능 탭: 칸 빨간(`#FF4466`) 플래시 + 화면 짧게 흔들림 + 라이프 다이아몬드 깨짐 연출
  - 버그 놓침: 칸이 짧게 빨갛게 깜박 + 라이프 다이아몬드 깨짐 연출
  - 보드 확장(45초): 3×3 칸이 바깥으로 밀려나며 4×4로 재배치(약 0.6초), `LEVEL UP` 대신 `SCALING UP` 텍스트
  - 게임 오버 시 화면 흔들림(짧게)
- **사운드:** 잡기(콤보에 따라 음 높이 상승, 상한 있음), 단단한 버그 1타(금 가는 소리), 골든, 기능 탭(에러 부저), 놓침, 보드 확장, 게임 오버. BGM은 Stack Up처럼 코드 합성 루프(곡은 다르게, 좀 더 빠른 템포). BGM/SFX 분리와 볼륨은 Stack Up 오디오 구조를 그대로 사용, 설정은 게임별 키로 localStorage에 저장
- **진동:** 기능 탭, 버그 놓침, 게임 오버 때 `navigator.vibrate`로 짧은 진동 (미지원 기기는 조용히 무시, iOS Safari는 미지원). 옵션 패널에 Vibration 항목 추가, localStorage 저장
- Reduced motion(OS 설정 또는 옵션의 수동 설정)이면 화면 흔들림, 큰 입자, 보드 확장 애니메이션 축소 (확장은 짧은 페이드로 대체)

## 핵심 규칙
1. 라이프 3개로 시작. 최대 3
2. 보드는 3×3으로 시작. 플레이 시간 45초에 4×4로 한 번 확장된다
3. 빈 칸에 오브젝트(일반 버그, 단단한 버그, 골든 버그, 기능)가 출현하고, 노출 시간이 지나면 사라진다
4. **버그(일반/단단한/골든)를 노출 시간 안에 잡지 못하면 라이프 -1**, 콤보 리셋
   - 단, 골든 버그를 놓치면 라이프는 깎이지 않는다 (보너스 오브젝트이므로)
5. **기능을 탭하면 라이프 -1**, 콤보 리셋, 기능은 즉시 사라짐. 기능이 그냥 사라지면 아무 일 없음
6. 일반 버그는 1탭, 단단한 버그는 2탭에 잡힌다. 단단한 버그를 1탭만 하고 시간이 끝나면 놓친 것으로 처리
7. 골든 버그를 잡으면 +50점, 그리고 라이프가 3 미만이면 라이프 +1
8. 빈 칸을 탭하면 콤보만 리셋 (라이프, 점수 변화 없음)
   > Task 006에서 변경: 빈 칸 탭은 라이프 -1, 콤보 리셋. 칸 밖은 영향 없음
9. 라이프가 0이 되면 즉시 게임 오버. 화면에 남은 오브젝트는 판정하지 않는다
10. 보드 확장 순간 화면에 있던 오브젝트는 페널티 없이 사라지고, 확장 연출 동안(1.5초) 출현이 멈춘다
11. 같은 칸에서 오브젝트가 사라진 뒤 짧은 쿨다운(0.2초) 동안은 그 칸에 다시 출현하지 않는다
12. 난이도는 **플레이 시간**(일시정지 시간 제외)에 따라 연속적으로 오른다 (아래 표, 각각 상한/하한 있음)
13. 같은 시드면 같은 출현 순서와 위치 (데일리 챌린지 대비)

## 점수
- 일반 버그 +10, 단단한 버그 +25, 골든 버그 +50
- 기본 점수 × 콤보 배율. 콤보 = 연속으로 잡은 버그 수 (단단한 버그는 2타째에 1 증가)
  | 콤보 | 배율 |
  |---|---|
  | 0~4 | ×1 |
  | 5~9 | ×2 |
  | 10~19 | ×3 |
  | 20 이상 | ×4 (상한) |
  - 배율은 해당 버그를 잡아 콤보가 오른 **뒤의** 값으로 계산
- 콤보 리셋: 버그 놓침, 기능 탭, 빈 칸 탭
- 점수는 줄어들지 않는다 (감점 없음. 실수의 대가는 라이프와 콤보)
- 리더보드 값은 최종 점수 (보조: 잡은 버그 수, 최대 콤보, 생존 시간)

## 조작과 화면
- **입력:** Pointer Events(`pointerdown`)로 마우스, 터치, 펜을 통합 처리. 판정은 칸 전체 영역
- **멀티터치:** 서로 다른 칸을 동시에 탭할 수 있다. 포인터마다 독립 처리(`pointerId`), 한 번의 `pointerdown` = 한 번의 탭. 캔버스에 `touch-action: none`, 더블탭 확대/길게 누르기 메뉴 방지
- 입력 좌표 → 칸 인덱스 변환은 순수 함수로 분리해서 테스트 (DPR, 레터박스 오프셋 포함)
- 연타 방지: 게임 오버 직후 짧은 입력 무시
- 흐름: 타이틀 → 플레이 → 게임 오버(점수, 최고 기록, NEW BEST, 닉네임 입력, 리더보드 Top 10) → 재시작. 플레이 중 HUD에 BEST 표시 (Stack Up과 같은 방식)
- 사이트 iframe과 모바일 세로 화면에 맞게 크기 조정 (보드는 화면 짧은 변 기준 정사각형, 4×4에서도 HUD와 겹치지 않게), 탭이 숨겨지면 일시정지
- 사운드는 첫 사용자 입력 이후에 시작 (브라우저 자동 재생 정책)
- 옵션 패널은 Stack Up과 같은 구성(BGM, SFX, 볼륨, Reduced motion, Reset data) + Vibration. 버튼 위치도 Stack Up과 동일(우상단)

  src/view/      # Canvas 렌더링, 보드 레이아웃, 오브젝트 스프라이트, VFX, 점수 팝업

  src/input/     # Pointer Events, 좌표 → 칸 매핑, 진동
  src/assets/    # Geist woff2, DevCol 로고 PNG (Stack Up에서 복사)

  leaderboard/   # 기존 그대로 사용 (game_id만 'bug-squash'로). 유일한 공통 모듈

- rng, 글로우 스프라이트 캐시, 별 패럴랙스/그리드, AudioContext 언락과 BGM/SFX 버스, 기록/옵션/frameClock/폰트 로더는 Stack Up 코드를 bug-squash 안에 복사해서 쓴다. `games/stack-up/`은 수정하지 않는다
- core의 입력은 `tap(cellIndex)`, 시간은 `update(dt)`. 결과는 이벤트 목록(잡음, 놓침, 기능 탭, 라이프 변화, 확장 등)으로 돌려주고 view/audio가 그걸 보고 연출한다
- **글로우는 매 프레임 shadowBlur로 그리지 않고**, 시작할 때 오브젝트 종류별/색별 스프라이트를 오프스크린 캔버스에 미리 그려서 재사용. 스케일 애니메이션은 drawImage 크기로 처리
- 입자와 점수 팝업은 풀링
- 리더보드 서버 연동은 이 Task 범위 밖. 인터페이스 + localStorage Mock만
