상태: 확정 (구현 시작 가능)
작성일: 2026-10-14
플랫폼: 웹 (TypeScript + Canvas 2D). 저장소 `devcol-arcade-web`, 규칙은 `CLAUDE.md`
선행: Task 004 (`task/004-bug-squash`, 아직 main 미머지). 이 브랜치에서 `task/005-bug-squash-redesign` 생성
에셋: 무료 + 상업적 사용 가능한 것만 (`docs/assets.md`에 기록), 사운드는 코드 합성

## 배경
- Task 004 결과의 배경·소리가 Stack Up과 너무 비슷함 → Bug Squash는 **완전히 다른 컨셉(레트로 터미널)** 으로 바꾼다. 앞으로의 모든 게임도 서로 다른 컨셉으로 만든다
- 리더보드 점수는 게임마다 완전히 따로 간다. `shared`의 역할은 **여러 게임의 순위를 모아 전체 랭킹을 만들기 위한 공통 기반** (예: 플레이어 A가 두 게임 모두 1위인지 확인)
- 이 명세는 Task 004 명세의 **"비주얼: Neon", "디테일 > 움직이는 배경/VFX/사운드", 폰트, 리더보드 구조** 부분을 대체한다. 게임 규칙, 점수, 수치, 조작, 화면 흐름은 Task 004 그대로

## 1. 리더보드: 게임별 분리 + 통합 랭킹 기반

### 구조 (`shared/`)
```
shared/
  leaderboard/   # 게임 무관 리더보드 (게임별 stats 타입은 제네릭)
  player/        # 게임 간 공통 플레이어 프로필 (playerId, nickname)
  ranking/       # 통합 랭킹용 공통 계약 + 플레이어별 게임 순위 수집
```
- **엔트리:** `{ playerId, nickname, score, stats, ts }`. `stats`는 게임마다 다른 타입 (제네릭)
  - Stack Up: `{ floors, maxCombo }`
  - Bug Squash: `{ bugsCaught, maxCombo, survivalSec }`
- **서비스:** `LeaderboardService<TStats>`에 `readonly gameId` 추가 (`'stack-up'`, `'bug-squash'`). 게임은 계속 이 인터페이스로만 접근
- **저장:** 게임별 키는 그대로 (`stackup.leaderboard`, `bugSquash.leaderboard`). 다른 게임 기록과 절대 섞이지 않음
- **기존 기록 마이그레이션:** 읽을 때 옛 형식(`floors`, `maxCombo`가 최상위, `playerId` 없음)을 새 형식으로 변환. 기존 Stack Up 기록이 사라지지 않아야 함
- **플레이어 프로필 (`shared/player`):** 게임 간 공통 `playerId`(처음 한 번 생성하는 랜덤 id)와 `nickname`
  - 키: `devcol.player.id`, `devcol.player.nickname`
  - 공통 닉네임이 없으면 기존 게임별 닉네임(`stackup.nickname`, `bugSquash.nickname`)에서 한 번 가져옴
  - 닉네임 입력은 두 게임 모두 이 프로필을 읽고 씀
  - 게임의 Reset data는 그 게임 기록(BEST, 리더보드)만 지우고 플레이어 프로필은 지우지 않음
- **통합 랭킹 기반 (`shared/ranking`):**
  - 계약 `RankingSource = { gameId; getTop(n) }` (LeaderboardService가 그대로 만족)
  - 순수 함수 `collectPlayerRanks(sources, n)` → 플레이어(`playerId`)별로 `{ nickname, ranks: { [gameId]: 순위 } }`. 예: A가 두 게임 모두 1위면 `{ 'stack-up': 1, 'bug-squash': 1 }`
  - 여러 게임 순위를 하나의 전체 순위로 합치는 계산 방식과 대시보드 UI는 이 Task 범위 밖 (대시보드 작업 때 결정)
- **Stack Up 수정 범위:** 리더보드 엔트리 형식, 공통 플레이어 프로필 사용만. 화면, 연출, 사운드, 게임 동작은 바꾸지 않음. 기존 Stack Up 테스트는 필요한 만큼만 고치고 모두 통과

## 2. 비주얼: 레트로 터미널
Stack Up(어두운 보라 네온, 별 패럴랙스, 원근 그리드)과 겹치는 요소를 쓰지 않는다. 기존 `stars.ts`, 원근 그리드, 보라 그라디언트는 Bug Squash에서 제거.

| 요소 | 값 |
|---|---|
| 배경 | 거의 검정 단색 `#050A07` |
| 코드 로그 | 화면 전체에 **글자 대신 짧은 막대 조각으로 그린 코드 줄**(들여쓰기, 길이 랜덤), `#39FF88` 알파 6~10%. 터미널 출력처럼 한 줄씩 위로 밀려 올라가고, 맨 아래 줄은 타이핑되듯 늘어남. 한 겹 (패럴랙스 아님) |
| CRT 오버레이 | 가로 스캔라인(2px 주기, 알파 약 8%) + 비네팅. 오프스크린에 한 번 그려 매 프레임 drawImage. 전체 밝기 미세 깜박임(±2%) |
| 칸 | **각진 사각형**(모서리 반경 0), 외곽선 `#1E5C38`, 채움 `#0A140E`. 왼쪽 위에 글자 없는 짧은 타이틀바 장식. 오브젝트가 있으면 외곽선 `#39FF88` |
| 일반 버그 | `#FFB000` 앰버. **픽셀 아트**(블록 그리드) 벌레, 약한 CRT 번짐 글로우 |
| 단단한 버그 | `#FF7A1A` 주황. 일반보다 큰 픽셀 그리드 + 등껍질 테두리 2겹. 1타 후 픽셀이 빠진 금 간 표시 |
| 골든 버그 | `#FFF6D0` 밝은 흰빛. 일반 버그 모양 + 반전 블록 커서처럼 깜박이는 하이라이트 |
| 기능 | `#3FE0FF` 시안. 픽셀 톱니 (버그와 실루엣이 확실히 다름) |
| 에러 색 | `#FF3B3B` (기능 탭, 놓침, 게임 오버) |
| 폰트 | **JetBrains Mono** (OFL 1.1) — 게임 안 모든 텍스트. Bug Squash에서 Geist는 제거 |
| 점수 | `#39FF88` 굵은 고정폭 숫자 + 약한 번짐 |
| 콤보 배율 | `x2` 형태, `#FFB000`. 배율이 오를 때 반전 블록으로 깜박 |
| 라이프 | 우상단, **블록 3개** `#39FF88` (잃으면 외곽선만, 깨질 때 픽셀로 흩어짐) |
| 로고 | 좌상단 DevCol 로고 (`devcol-logo-dark.png`, 그대로). 플레이 중 상단 가운데 `BUG SQUASH` 문구 `#39FF88` 흐리게 |
| 게임 오버 | 화면 어둡게, `GAME OVER` `#FF3B3B`, 점수 `#39FF88`, `BEST n` `#FFB000`, 작은 `Build failed` `#FF3B3B`, `> Tap to retry_` (`_` 깜박임) `#39FF88` |
| 타이틀/옵션 | 같은 팔레트와 고정폭 폰트로 터미널 창 스타일. 옵션 항목 구성은 그대로 |

### VFX (Task 004 VFX를 대체)
- 버그 잡기: 스프라이트가 **픽셀 조각으로 분해**되어 흩어짐 + 칸 외곽선 플래시 + 점수 팝업
- 단단한 버그 1타: 픽셀 빠짐(금) + 칸 안 **가로 줄 어긋남 글리치**(짧게)
- 골든 잡기: 칸 반전 플래시 + 흰 픽셀 + `+1 LIFE` / `+50` 팝업
- 점수 팝업: 고정폭 `+20`이 떠오르며 페이드 (HUD 띠로 올라가지 않음, Task 004 규칙 유지)
- 기능 탭: 칸 빨간 반전 블록 플래시 + **화면 글리치**(가로 줄 어긋남 약 0.2초, 화면 흔들림 대신) + 라이프 블록 깨짐
- 버그 놓침: 칸 빨간 깜박임 + 라이프 블록 깨짐
- 보드 확장: 칸 재배치(0.6초)는 유지, `SCALING UP` 문구가 **한 글자씩 타이핑**되듯 나타남 (`> SCALING UP_`)
- 게임 오버: **CRT 꺼짐 효과**(화면이 가로 한 줄로 줄어들었다가 게임 오버 화면) 약 0.4초
- Reduced motion: 글리치·CRT 꺼짐·화면 깜박임 끔(짧은 페이드로 대체), 픽셀 조각 수 축소, 타이핑은 즉시 표시
- 원칙 유지: 매 프레임 shadowBlur 금지(스프라이트 캐시), 입자/팝업 풀링, 루프 안 할당 최소화

## 3. 사운드: 칩튠 + 터미널 (Task 004 사운드를 대체)
AudioManager 구조(언락, BGM/SFX 버스, 볼륨, 설정 키 `bugSquash.audio.*`)는 유지하고 소리만 바꾼다.

| 소리 | 내용 |
|---|---|
| BGM | **칩튠**: 펄스파 리드(듀티 12.5%/25%, PeriodicWave) 멜로디 + 삼각파 베이스 + 노이즈 드럼(킥은 피치 스윕). 150 BPM 근처, 8마디 루프, 아르페지오 반복이 아니라 멜로디가 있는 곡 |
| 잡기 | 기계식 키보드 클릭(짧은 노이즈 + 고역 틱) + 콤보에 따라 올라가는 8비트 블립 (상한 있음) |
| 단단한 버그 1타 | 짧은 글리치음 (빠르게 바뀌는 계단식 주파수) |
| 골든 | 8비트 코인 아르페지오 |
| 기능 탭 | 터미널 에러 벨 (낮은 펄스 비프 2회) |
| 놓침 | 짧은 하강 블립 (기능 탭보다 덜 거슬리게) |
| 보드 확장 | 8비트 상승 스윕 + 빠른 타자음 몇 개 |
| 게임 오버 | CRT 전원 꺼짐 (고역 하강 휘이익 + 짧은 험) |

- 골든 놓침은 무음 (Task 004와 동일)
